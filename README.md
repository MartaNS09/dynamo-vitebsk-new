# Динамо Витебск - СДЮШОР

Современный веб-сайт для Специализированной детско-юношеской школы олимпийского резерва "Динамо" Витебск.

## 🚀 Особенности

- **Современный дизайн** - Чистый, профессиональный интерфейс
- **Адаптивность** - Идеально на всех устройствах
- **Темная/светлая тема** - Переключение между темами
- **RTL поддержка** - Поддержка правого-левого направления
- **Плавные анимации** - Современные переходы и эффекты
- **Быстрая загрузка** - Оптимизированная производительность

## 🛠 Технологии

- Next.js 14+ с App Router
- TypeScript для надежности
- SCSS для стилей
- Ant Design для UI компонентов
- Framer Motion для анимаций

## 📱 Страницы

- Главная
- История школы
- Отделения и виды спорта
- Тренерский состав
- Достижения
- Контакты

## 🎨 Дизайн

- Цветовая схема: синий, золотой, белый
- Шрифты: Plus Jakarta Sans, Space Grotesk
- Стеклянный эффект (glass morphism)
- Градиенты и тени

## 🎨 Design System

- **В резерве**: Ant Design (установлен, но не используется)
- **Иконки**: Кастомные SVG компоненты в `src/components/icons/`

## 🚀 Запуск проекта

\`\`\`bash
npm install
npm run dev
\`\`\`

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## Analytics (GA4 + Yandex Metrika)

Добавьте в `.env.local`:

```bash
NEXT_PUBLIC_GA_MEASUREMENT_ID=G-XXXXXXXXXX
NEXT_PUBLIC_YM_COUNTER_ID=12345678
```

Что настроено:
- автоматический `page_view`/`hit` при смене маршрута App Router;
- событие `application_submit` при успешной отправке заявки;
- событие `phone_click` при клике по ссылке `tel:`.
- событие `enrollment_cta_click` при переходе на страницу записи;
- событие `enrollment_page_view` при открытии страницы `/enrollment`;
- событие `admin_login_submit` при успешном входе в админку.
